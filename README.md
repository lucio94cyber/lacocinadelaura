Un espacio digital dedicado a presentar productos de pastelería artesanal, acercar nuestras propuestas a los clientes y facilitar los pedidos online.

## 🌐 Sitio web

[**Visitar La Cocina Laura →**](https://lacocinadelaura.netlify.app/)

## ✨ Características

- Presentación de productos de pastelería.
- Catálogo visual de productos.
- Diseño cálido y atractivo.
